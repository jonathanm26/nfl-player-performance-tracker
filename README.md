# NFL Player Performance Tracker

An interactive NFL player performance dashboard built with Python, Pandas, Streamlit, and Plotly.

## Features

- Search NFL players
- Filter by team and position
- Track passing and rushing statistics
- View estimated fantasy performance
- Compare players with interactive charts
- Clean dashboard for portfolio and GitHub presentation

## Tech Stack

- Python
- Pandas
- Streamlit
- Plotly

## Project Structure

```text
nfl-player-performance-tracker/
│
├── data/
│   └── nfl_player_stats.csv
│
├── app.py
├── requirements.txt
├── README.md
└── .gitignore
```

## How to Run

Install the required packages:

```bash
pip install -r requirements.txt
```

Run the Streamlit app:

```bash
streamlit run app.py
```
